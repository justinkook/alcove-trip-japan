# Starter

This repository is an **empty Japan trip scaffold**, not a finished itinerary.

Checks fail while this file exists and while `starter: true` in `trip.yaml`.

Before you use the fork as your own trip:

- Browse the fleshed sample under [`examples/japan-summer-2026/`](examples/japan-summer-2026/) (copy what you want into the repo root, or plan from scratch).
- Replace `traveler_ids`, dates, and add nodes under `itinerary/`, `bookings/`, `dependencies/`.
- Keep or retune `hard_constraints` — they are opinionated Japan defaults, not universal law.
- Delete this file.
- Set `starter` to false.

Lessons and traveler profiles are not here — they live in Alcove.
