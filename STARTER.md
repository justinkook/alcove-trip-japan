# Starter

This repository is a claimable Japan summer itinerary, not an empty schema demo.

Checks fail while this file exists and while `starter: true` in `trip.yaml`.

Before you use the fork as your own trip:

- Replace `traveler_ids`, dates, and any nodes that do not fit.
- Keep or retune `hard_constraints` — they are opinionated Japan-summer defaults, not universal law.
- Delete this file.
- Set `starter` to false.

The sample shows lodgings, transfers with margins, meals that respect gap limits, one early Fushimi morning, a weather-sensitive photo block with prep time and a fallback, a dense Nara→Osaka day, and a budget with no hard cap. Lessons and traveler profiles are not here.
